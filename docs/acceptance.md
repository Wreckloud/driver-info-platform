# V1 验收清单

## 自动化验证

```sh
cd backend && mvn test
cd ../frontend && npm test && npm run build
```

## 司机端真机

- Android 微信和 iPhone 微信均可扫描固定二维码进入 `/driver`。
- 首次允许定位后，司机页显示“已获取当前位置”且不暴露坐标和精度；提交成功页优先显示文字地址，后台可见地址、坐标、精度及定位时间。
- 分别验证拒绝授权、关闭系统定位、10 秒超时和设备无法定位，所有情况仍可提交。
- 重新定位失败后不能沿用旧坐标。
- 连续点击和网络重试只产生一条记录。
- 提交成功页显示姓名、车牌、目的地、定位状态、起始位置和服务器提交时间。
- 再次扫码只回填姓名、电话、车牌、车型；目的地和定位为空。
- “清除常用信息”会清除本机保存内容。

## 管理员端

- 错误密码提示一致；连续失败 5 次后同一来源锁定 15 分钟。
- 未登录无法访问列表、详情、修改、删除和导出接口。
- 电脑显示表格、手机显示卡片，功能一致且无横向页面溢出。
- 默认最新记录在顶部；20/50/100 分页正确。
- 7 天内同时显示相对时间和较淡的精确时间，满 7 天只显示完整时间；相对时间持续更新且以服务器时间为准。
- 日期范围包含开始日和结束日全部记录，关键词可匹配姓名、车牌或目的地。
- 修改只能改变司机填写的五个字段，定位和时间保持不变。
- 删除后记录从列表、详情、搜索和 Excel 消失，数据库行仍存在。
- Excel 无筛选时导出全部有效记录，有筛选时只导出当前筛选结果。

## 部署与恢复

- `deploy/scripts/preflight.sh` 检查通过，`.env` 不含示例值，证书与私钥匹配且未临近过期。
- HTTP 自动跳转 HTTPS，浏览器定位权限可以正常弹出。
- `/driver/success`、`/admin/records/:id` 刷新不会出现 Nginx 404。
- 腾讯地图不可用时，带坐标的登记仍成功，后台明确显示文字地址解析失败。
- 重启 API 后数据保留、管理员会话失效并可重新登录。
- 完成一次备份、恢复演练，并确认恢复后记录数量和内容一致。
